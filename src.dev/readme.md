## No music must be lost; all data must be preserved.

### The Container

- Supports a schema generated from or based on the internal standard that describes events and their variants.
- Data is stored in binary with a lookup IL to generalize it, or in an entirely free/open format.
- May contain hashed/protected vendor data when a primary proprietary format is also preserved.
- Generalizes project data and allows tiers that modify a tree to archive, serialize, and describe changes for a project.
- Any point in the container data can be referenced historically.
- Allows converting inner data formats (complete assets, presets, etc.) into other formats.
- A container will typically hold the latest save, but it can be combined with other containers in the same format via set operations.
- Once converted, data is readable and diffable.

### Why Use It

- Fast by default, so hosts can offer it as an export or save option.
- All music must be saved and interchangeable.
